ประเด็นที่ควร Confirm กับ BA
เพื่อให้ Requirement ชัดเจน ควรถามเพิ่มว่า
ระบบต้องเรียก DOPA เฉพาะกรณีที่เลขประจำตัวประชาชนผ่านการตรวจสอบรูปแบบและ Check Digit แล้วใช่หรือไม่ และกรณีผู้รับประโยชน์/ผู้ปกครองที่เป็นชาวต่างชาติ (Passport) ให้ข้ามการเรียก DOPA ใช่หรือไม่

Business Rule
หาก Relationship = ผู้เอาประกันภัย (Self)
อนุญาตให้เลขประจำตัวประชาชนของผู้รับผลประโยชน์ตรงกับผู้เอาประกันภัย
ไม่ต้องตรวจสอบ Duplicate Citizen ID
หาก Relationship ≠ ผู้เอาประกันภัย
ระบบต้องตรวจสอบว่า Citizen ID ของผู้รับผลประโยชน์ ≠ Citizen ID ของผู้เอาประกันภัย
หากเป็นเลขเดียวกัน ให้แสดง Validation Message และไม่อนุญาตให้บันทึกข้อมูล

DOPA (กรมการปกครอง) ที่เชื่อมผ่าน API ในองค์กร เช่น บริษัทประกันหรือธนาคาร ไม่ได้เปิดให้ค้นหาข้อมูลทั้งหมดในทะเบียนราษฎร แต่จะให้บริการ Verification (ตรวจสอบความถูกต้องของข้อมูล) ตามสิทธิ์ที่หน่วยงานได้รับ

โดยทั่วไป DOPA API สามารถตรวจสอบได้ดังนี้
